# Exercício ES6 — Filtro de Alunos Aprovados

## 🎯 Objetivo
Praticar recursos do ES6 (arrow functions, destructuring, filter, template literals)
por meio de um filtro de alunos com nota maior ou igual a 6.

## 🚀 Como executar
```bash
npm install
npm start      # executa o script
npm test       # roda os testes unitários
```
